What it does

You give PositionCalculator an item, usually a target and optionally a boundary. It measures them and returns how far the item has to move. It does not move anything itself.

Quick start

Create an instance with an item and a target, then apply moveBy to the item. Both reference points use the form "vertical horizontal": 

const calculator = new PositionCalculator({
    item: tooltip,
    target: button,
    itemAt: "top center",
    targetAt: "bottom center",
});
const { moveBy } = calculator.calculate();

The full steps, including the IIFE build and a check of the result, are in Getting started.
