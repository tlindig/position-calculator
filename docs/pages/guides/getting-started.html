Goal

Place a small tooltip below a button. At the end, the tooltip is centred under the button and touches it. The library calculates the offset. You move the element.

Before you start

  • Node.js 24 or later, if you install with npm.
  • An element to move (the item) and an element to place it at (the target), both in the page.

Steps

1. Install

npm install @tlindig/position-calculator

2. Import

In an ES module, import the named export:

import { PositionCalculator } from "@tlindig/position-calculator";

Without a bundler, load the IIFE build from node_modules/@tlindig/position-calculator/dist/ with a script tag, file position-calculator.iife.min.js. It defines the global PositionCalculator.

3. Create the instance and calculate

The item must be positioned, for example with position: absolute, so that moveBy can be applied to its left and top. Give the item a target and the reference points: 

const tooltip = document.querySelector("#tooltip");
const button = document.querySelector("#button");

const calculator = new PositionCalculator({
    item: tooltip,
    target: button,
    itemAt: "top center",
    targetAt: "bottom center",
});

const result = calculator.calculate();
const style = getComputedStyle(tooltip);
tooltip.style.left = parseFloat(style.left) + result.moveBy.x + "px";
tooltip.style.top = parseFloat(style.top) + result.moveBy.y + "px";

itemAt is the point of the item that meets targetAt, the point of the target. Both use the form "vertical horizontal". moveBy is the distance the item has to move, in pixels.

Try it

The code above is checked in a browser against the built IIFE file. The tooltip is centred under the button, its top edge is at the bottom edge of the button, and the horizontal centres match. Use the playground to change the placement and see the result.

Coming from 1.x

Version 1 was a jQuery plugin. Version 2 is a standalone library: the ESM build has no jQuery dependency. Its API differs from 1.x, so check your calls against the constructor and result pages instead of reusing 1.x code.
