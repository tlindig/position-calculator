How it works

  1. The popup is the item, the Add line button is the target, and the dashed box is the boundary. The Remove line button only changes the content of the popup.
  2. itemAt: "bottom left" and targetAt: "top right" put the popup above the button, with its lower left corner at the upper right corner of the button.
  3. flip: "both" tries the opposite placement when the first one overflows. The popup grows with every line, and from the fourth line the room above the button is too small, so it goes below. Removing a line brings it back above.
  4. stick: "all" is the last resort. From the sixth line neither side fits completely, and the popup is pulled back inside the box. The example allows at most eight lines.
  5. Every added or removed line changes the size of the popup. The example calls resize() before calculate() because a calculator keeps the size it has read.
  6. The example applies moveBy as a transform and removes the transform before the next calculation, because calculate() starts from where the popup is now.
  7. A click on the popup or the Escape key closes it. The library does not handle that. It only calculates a position.

Variations

  • In the playground, set stick to "none" and add eight lines: the popup leaves the box at the bottom.
  • Set flip to "none": the popup stays above the button and leaves the box at the top from the fourth line.
